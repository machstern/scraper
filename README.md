install node.js version 22 on your computer
after install, open a powershell window and type "node -v", if installed it should print the node version. you might need to close and reopen all powershell windows or reboot

clone or download this repository to a folder on your pc
copy the .env.example file to .env and put in the real site url

run "npm i"
run "npx playwright test"

change the start and end set IDs in download.spec.ts as needed
